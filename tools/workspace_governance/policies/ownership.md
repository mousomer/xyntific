# Layer ownership policy

The shared pack owns generic schema and diagnostic semantics. A workspace owns
membership, relationships, and workspace-only defaults. A project owns its
executable facts and references human semantic authorities. A local overlay may
only select machine execution locations permitted by the project contract.

Contradictions are errors, not precedence decisions. Deduplicate identical facts
owned by one layer; regenerate stale mirrors; update compatibility facades from
their canonical source; repair environment mismatches in the environment; and
send conflicts between human authorities through explicit governance review.
